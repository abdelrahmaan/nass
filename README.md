# nass — عدّة نصوص عربية

الـ starter repo لمسار **Claude Code في 15 يوم** من AIXpert.

خدمة صغيرة بتصحّح أخطاء الكتابة الشائعة في النص العربي: أرقام عربية-هندية، تطويل،
تشكيل، مسافات، علامات ترقيم، وكلمات غلط شائعة. صفحة بحث واحدة، وserver صغير، وطقم
اختبارات، وeval بيدّيك رقم.

**صفر dependencies.** كل حاجة من مكتبات Node نفسها. مفيش `npm install`.

---

## شغّله

```bash
git clone https://github.com/abdelrahmaan/nass.git
cd nass
npm start            # أو: node tools/serve.js
```

وبعدين افتح <http://localhost:8080>.

```bash
npm test             # الاختبارات
npm run eval         # الدرجة
npm run check        # تقرير تقدّمك في المسار
```

محتاج **Node 20+** — وهو مطلوب أصلًا لتثبيت Claude Code، فغالبًا عندك.

---

## المشروع ناقص عن قصد

أول ما تشغّل الـ eval هتلاقي:

```
الدرجة: 10/50  (20%)
```

ده مش bug. الـ repo بيبدأ بقاعدتين شغالين بس — `digits` و`tatweel` — والباقي
مكتوب كـ `PLANNED` في `lib/rules.js` مستني تكتبه.

الرقم اللي تقدر توصله بالقواعد كلها **45/50**. الخمسة الباقيين مش عايزين قاعدة،
عايزين قاموس صرفي — واكتشاف ده بنفسك هو اليوم 12.

الـ `eval/cases.json` هو أغلى ملف هنا. ماتعدّلش `out` علشان تعدّي حالة؛ ده غش على
نفسك والرقم بيبقى ملوش معنى.

## حاجتين لازم تعرفهم

**فيه عيب بصري مقصود في الصفحة.** مش هقولك هو فين — اليوم 8 هو اللي هيخلّي Claude
يلاقيه بـ `/chrome` ويصلّحه. لو لقيته دلوقتي بالصدفة، سيبه لحد اليوم ده.

**`logs/checks.log` مش موجود لحد ما تستخدم الصفحة.** اليوم 6 محتاجه فيه كلام — يعني
لازم تشتغل على الأداة فعلًا مش تتفرج عليها.
